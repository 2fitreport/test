# 성과정산 시스템 가이드

> 이 문서는 성과정산 페이지에서 **각 직급별로 무엇이 보이고, 어떻게 계산되는지**를 설명합니다.

---

## 1. 직급 구분

| 직급 | 레벨 | 설명 |
|------|------|------|
| 대표자 | 1 | 회사 전체를 총괄하는 최고 관리자 |
| 대표실무자 | 2 | 실무를 총괄하는 관리자 |
| 실무자 | 3 | 문서를 배정받아 처리하는 담당자 |
| 영업자 (일반) | 4 | 기업을 등록하고 상담하는 영업 담당자 |
| 영업자 (소속대표) | 4 | 소속 영업팀의 대표 (같은 소속 영업자들을 관리) |
| 검수자 | 6 | 문서를 검수하는 담당자 |

---

## 2. 페이지 구성

성과정산 페이지는 크게 **5개 영역**으로 구성됩니다.

```
┌─────────────────────────────────────────────────┐
│  ① 상단 통계 카드 (5개)                          │
│  ┌───────┬───────┬───────┬───────┬───────┐      │
│  │이번달 │이번달 │ 누적  │ 누적  │전환율 │      │
│  │ 매출  │승인금액│ 매출  │승인금액│      │      │
│  └───────┴───────┴───────┴───────┴───────┘      │
├─────────────────────────────────────────────────┤
│  ② 케이스별 매출 정산 (테이블)                    │
│  - 업체명, 승인금액, 실제매출, 영업자,            │
│    유입방식, 지급수수료, 지급예정일                │
├─────────────────────────────────────────────────┤
│  ③ 년별 매출 추이 (막대 차트)                     │
├─────────────────────────────────────────────────┤
│  ④ 영업자 성과 (테이블)                          │
│  - 담당자, 상담수, 케이스수, 승인금액, 전환율      │
├─────────────────────────────────────────────────┤
│  ⑤ 실무자 성과 (테이블) ← 일부 직급만 표시        │
│  - 담당자, 상담수, 케이스수, 승인금액, 전환율      │
└─────────────────────────────────────────────────┘
```

## 3. 직급별 상세 설명

---

### 3-1. 대표자 (레벨 1)

**한 줄 요약:** 회사의 모든 데이터를 제한 없이 볼 수 있습니다.

#### 보이는 영역
| 영역 | 표시 여부 |
|------|----------|
| ① 상단 통계 카드 | O |
| ② 케이스별 매출 정산 | O |
| ③ 년별 매출 추이 | O |
| ④ 영업자 성과 | O |
| ⑤ 실무자 성과 | O |

#### 데이터 범위
- **모든 문서**를 볼 수 있음 (제한 없음)
- **모든 영업자**의 성과가 표시됨
- **모든 실무자**의 성과가 표시됨
- 정산 테이블에 **모든 영업자의 수수료 내역**이 표시됨

#### 흐름
```
로그인
  ↓
성과정산 페이지 진입
  ↓
회사 전체 문서 기준으로 통계/정산/차트 계산
  ↓
모든 영업자·실무자 성과 표시
```

---

### 3-2. 대표실무자 (레벨 2)

**한 줄 요약:** 대표자와 거의 동일하지만, **"admin 배정" 문서는 제외**됩니다.

#### 보이는 영역
| 영역 | 표시 여부 |
|------|----------|
| ① 상단 통계 카드 | O |
| ② 케이스별 매출 정산 | O |
| ③ 년별 매출 추이 | O |
| ④ 영업자 성과 | O |
| ⑤ 실무자 성과 | O |

#### 데이터 범위
- 담당자가 "admin"인 문서를 **제외**한 모든 문서
- **모든 영업자**의 성과 (단, admin 배정 문서는 제외하고 계산)
- **모든 실무자**의 성과
- 정산 테이블에 모든 영업자의 수수료 내역 표시

#### "admin 배정"이란?
> 아직 실무자에게 배정되지 않고 시스템(admin)이 임시로 관리하는 문서입니다.
> 대표실무자는 이런 미배정 문서를 통계에서 제외하고, 실제 업무가 진행 중인 문서만 봅니다.

#### 흐름
```
로그인
  ↓
성과정산 페이지 진입
  ↓
admin 배정 문서를 제외한 전체 문서 기준으로 계산
  ↓
모든 영업자·실무자 성과 표시
```

---

### 3-3. 실무자 (레벨 3)

**한 줄 요약:** 본인이 담당하는 문서와 관련된 영업자·실무자 성과만 볼 수 있습니다.

#### 보이는 영역
| 영역 | 표시 여부 |
|------|----------|
| ① 상단 통계 카드 | O (본인 담당 문서 기준) |
| ② 케이스별 매출 정산 | O (본인 담당 문서 기준) |
| ③ 년별 매출 추이 | O (본인 담당 문서 기준) |
| ④ 영업자 성과 | O (본인 담당 문서의 영업자만) |
| ⑤ 실무자 성과 | O (본인 + 관련 실무자) |

#### 데이터 범위
- **본인이 담당자로 배정된 문서**만 볼 수 있음
- 영업자 성과: 본인이 담당하는 문서의 영업자들만 표시
- 실무자 성과: 본인 + 같은 소속의 다른 실무자들

#### 흐름
```
로그인
  ↓
성과정산 페이지 진입
  ↓
"내가 담당하는 문서"만 조회
  ↓
그 문서들 기준으로 통계/정산/차트 계산
  ↓
내 문서에 관련된 영업자 성과 표시
  ↓
나 + 같은 소속 실무자 성과 표시
```

#### 예시
> 실무자 김철수가 A기업, B기업, C기업 문서를 담당하고 있다면:
> - 통계 카드: A, B, C 기업 문서 기준
> - 정산 테이블: A, B, C 기업의 수수료 내역
> - 영업자 성과: A, B, C를 등록한 영업자들의 성과
> - 실무자 성과: 김철수 본인 + 같은 소속 실무자들

---

### 3-4. 일반 영업자 (레벨 4, 소속대표 아님)

**한 줄 요약:** 본인이 직접 관련된 문서와 수수료만 볼 수 있습니다.

#### 보이는 영역
| 영역 | 표시 여부 |
|------|----------|
| ① 상단 통계 카드 | O (본인 관련 문서 기준) |
| ② 케이스별 매출 정산 | O (본인 수수료만) |
| ③ 년별 매출 추이 | O (본인 관련 문서 기준) |
| ④ 영업자 성과 | O (본인만) |
| ⑤ 실무자 성과 | X (표시 안 됨) |

#### 데이터 범위
- **본인이 등록한 문서** + **본인에게 상담요청으로 배정된 문서**
- 정산 테이블: **본인이 수수료를 받는 행만** 표시 (다른 영업자의 수수료는 보이지 않음)
- 영업자 성과: **본인 1명의 성과만** 표시
- 실무자 성과: 표시 안 됨

#### 정산 테이블 필터링 규칙
이 부분이 핵심입니다. 일반 영업자가 볼 수 있는 정산 행은 다음과 같습니다:

| 유입방식 | 표시 조건 |
|---------|----------|
| 기업등록 | 내가 직접 등록한 기업만 표시 |
| 상담요청 | 내가 상담요청을 보낸 건만 표시 (내가 받은 건은 수수료 0이므로 미표시) |
| 소개지급 | 내가 소개한 영업자의 문서가 승인된 경우만 표시 |

#### 흐름
```
로그인
  ↓
성과정산 페이지 진입
  ↓
"내가 등록한 문서" + "내가 상담요청한 문서" 조회
  ↓
통계/차트는 위 문서 기준으로 계산
  ↓
정산 테이블: 내가 수수료를 받는 행만 필터링
  ↓
+ 내가 소개자인 경우, 소개지급 행을 별도로 추가
  ↓
영업자 성과: 나 1명만 표시
```

#### 예시
> 영업자 이영희가:
> - A기업을 직접 등록 (기업등록) → 정산에 "기업등록 40%" 표시
> - B기업의 상담요청을 보냄 → 정산에 "상담요청 20%" 표시
> - 후배 박철수를 소개했는데, 박철수의 C기업이 승인됨 → 정산에 "소개지급 5%" 표시
> - 다른 영업자 김민수가 D기업을 상담요청하여 이영희에게 배정됨 → **이영희 정산에는 미표시** (수수료 0%)

---

### 3-5. 소속대표 (레벨 4, 소속대표 지정)

**한 줄 요약:** 같은 소속 영업팀 전체의 데이터를 볼 수 있습니다.

#### 보이는 영역
| 영역 | 표시 여부 |
|------|----------|
| ① 상단 통계 카드 | O (소속 전체 기준) |
| ② 케이스별 매출 정산 | O (소속 전체, 필터링 없음) |
| ③ 년별 매출 추이 | O (소속 전체 기준) |
| ④ 영업자 성과 | O (같은 소속 영업자 전원) |
| ⑤ 실무자 성과 | X (표시 안 됨) |

#### 데이터 범위
- **같은 소속의 모든 영업자 문서**를 볼 수 있음
- 정산 테이블: 소속 영업자들의 **모든 수수료 내역** 표시 (필터링 없음)
- 영업자 성과: 같은 소속 영업자 전원
- 실무자 성과: 표시 안 됨

#### "같은 소속"이란?
> 소속(소속명)은 영업 조직을 구분하는 단위입니다.
> 예를 들어 "서울팀" 소속대표는 "서울팀" 소속 영업자 전체의 데이터를 볼 수 있습니다.

#### 흐름
```
로그인
  ↓
성과정산 페이지 진입
  ↓
내 소속 확인 (예: "서울팀")
  ↓
"서울팀" 소속 모든 영업자의 문서 조회
  ↓
통계/정산/차트는 소속 전체 문서 기준으로 계산
  ↓
정산 테이블: 소속 영업자들의 모든 수수료 행 표시
  ↓
영업자 성과: 소속 영업자 전원 표시
```

#### 일반 영업자와의 차이
| 항목 | 일반 영업자 | 소속대표 |
|------|-----------|---------|
| 문서 범위 | 본인 관련만 | 소속 전체 |
| 정산 필터링 | 본인 수수료만 | 소속 전체 수수료 |
| 영업자 성과 | 본인 1명 | 소속 전원 |

---

### 3-6. 검수자 (레벨 6)

**한 줄 요약:** 담당 소속의 영업자 문서를 볼 수 있습니다.

#### 보이는 영역
| 영역 | 표시 여부 |
|------|----------|
| ① 상단 통계 카드 | O (담당 소속 기준) |
| ② 케이스별 매출 정산 | O (담당 소속 기준) |
| ③ 년별 매출 추이 | O (담당 소속 기준) |
| ④ 영업자 성과 | O (담당 소속 영업자) |
| ⑤ 실무자 성과 | X (표시 안 됨) |

#### 데이터 범위
- **담당 소속의 영업자들이 등록한 문서**만 조회
- 정산 테이블: 해당 문서들의 수수료 내역 표시
- 영업자 성과: 담당 소속의 영업자들
- 실무자 성과: 표시 안 됨

#### 흐름
```
로그인
  ↓
성과정산 페이지 진입
  ↓
내가 담당하는 소속 확인 (예: "서울팀", "부산팀")
  ↓
해당 소속 영업자들의 문서 조회
  ↓
통계/정산/차트는 해당 문서 기준으로 계산
  ↓
영업자 성과: 담당 소속 영업자들 표시
```

## 4. 수수료 계산 규칙

### 유입방식별 수수료율

모든 수수료는 **실제매출(revenue_amount)** 기준으로 계산됩니다.

| 유입방식 | 대상 | 수수료율 | 설명 |
|---------|------|---------|------|
| 기업등록 | 문서를 등록한 영업자 | **40%** | 영업자가 직접 기업을 발굴하여 등록한 경우 |
| 상담요청 | 상담요청을 보낸 영업자 (A) | **20%** | A영업자가 다른 영업자(B)에게 상담을 요청한 경우 |
| 상담요청 | 상담을 받은 영업자 (B) | **0%** | B영업자는 수수료 없음 (정산 테이블에 미표시) |
| 소개지급 | 소개한 사람 | **5%** | 영업자를 회사에 소개한 사람에게 지급 |

### 계산 예시

```
[ 기업등록 예시 ]
영업자 홍길동이 "ABC기업"을 직접 등록
  → 승인금액: 5,000만원
  → 실제매출: 3,000만원
  → 홍길동 수수료: 3,000 × 40% = 1,200만원

[ 상담요청 예시 ]
영업자 김철수(A)가 "DEF기업" 상담을 영업자 이영희(B)에게 요청
  → 승인금액: 8,000만원
  → 실제매출: 5,000만원
  → 김철수(A) 수수료: 5,000 × 20% = 1,000만원  (상담요청)
  → 이영희(B) 수수료: 0원  (표시 안 됨)

[ 소개지급 예시 ]
영업자 박민수가 회사에 홍길동을 소개함
홍길동이 "ABC기업"을 등록하여 승인됨
  → 실제매출: 3,000만원
  → 박민수 수수료: 3,000 × 5% = 150만원  (소개지급)
  → (홍길동은 별도로 기업등록 40% 수수료를 받음)
```

## 5. 통계 카드 계산 방법

상단의 5개 통계 카드는 다음과 같이 계산됩니다.

| 카드 | 계산 방법 | 기준 시점 |
|------|----------|----------|
| 이번달 매출 | 이번달 승인된 문서의 실제매출(revenue_amount) 합계 | 이번달 (지급예정일 기준) |
| 이번달 승인금액 | 이번달 승인된 문서의 승인금액 합계 | 이번달 (지급예정일 기준) |
| 누적 매출 | 전체 승인된 문서의 실제매출 합계 | 전체 기간 |
| 누적 승인금액 | 전체 승인된 문서의 승인금액 합계 | 전체 기간 |
| 전환율 | 이번달 케이스수 ÷ 이번달 상담수 × 100 | 이번달 |

> **참고:** "매출"은 대표자가 문서 승인 시 직접 입력한 실제매출(revenue_amount) 값을 사용합니다.

## 6. 성과 테이블 용어 설명

### 영업자 성과 / 실무자 성과 테이블 공통

| 컬럼 | 의미 | 계산 기준 |
|------|------|----------|
| 상담수 | 해당 월에 생성된 문서 수 | 문서 생성일(created_at) 기준 |
| 케이스수 | 해당 월에 승인된 문서 수 | 지급예정일(payment_date) 기준 |
| 승인금액 | 승인된 문서의 승인금액 합계 | 지급예정일 기준 |
| 전환율 | 상담 → 승인 비율 | 케이스수 ÷ 상담수 × 100 |

> **상담수와 케이스수의 날짜 기준이 다릅니다:**
> - 상담수: "이번달에 새로 들어온 상담이 몇 건인가?" (문서 생성일)
> - 케이스수: "이번달에 돈이 들어온 건이 몇 건인가?" (지급예정일)

## 7. 년별 매출 추이 차트

- **가로축:** 1월 ~ 12월
- **세로축:** 매출 (억원 단위)
- **막대 색상:** 현재 월은 진한 색, 나머지는 회색
- **매출 계산:** 해당 월 승인된 문서의 실제매출(revenue_amount) 합계 (억원 변환)
- **툴팁:** 막대에 마우스를 올리면 전년도 대비 증감률 표시

## 9. 보안 규칙

- **로그인하지 않은 사용자:** 모든 API 접근 차단 (401 오류)
- **유효하지 않은 직급 (레벨 0 등):** 모든 API 접근 차단 (403 오류)
- **직급별 데이터 격리:** 각 직급은 자신의 권한 범위를 넘는 데이터에 접근할 수 없음
- **일반 영업자:** 다른 영업자의 수수료 내역을 볼 수 없음
